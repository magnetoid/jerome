# Services Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let proofreading and translation use OpenAI, Gemini, Mistral, OpenRouter (open-weight models), an own server and, for translation, DeepL. Let LanguageTool use Premium credentials.

**Architecture:**
- Named OpenAI-compatible presets reuse `OpenAICompatProvider` with a fixed base URL and their own secret.
- DeepL is a provider with a `translate_texts` method. `run_translate_pass` calls it instead of `complete`, and builds the same `CompletionResult` the decoder already checks.
- LanguageTool credentials go on `LanguageToolClient`.

**Tech Stack:** Python 3.12, httpx, respx, FastAPI, React 19.

**Spec:** `docs/superpowers/specs/2026-11-24-services-design.md`

## Global Constraints

- Preset base URLs:
  - openai: `https://api.openai.com/v1`
  - gemini: `https://generativelanguage.googleapis.com/v1beta/openai`
  - mistral: `https://api.mistral.ai/v1`
  - openrouter: `https://openrouter.ai/api/v1`
- Secrets: `openai_api_key`, `gemini_api_key`, `mistral_api_key`, `openrouter_api_key`, `openai_compat_api_key`, `deepl_api_key`, `languagetool_api_key`. Plain setting: `languagetool_username`.
- DeepL: provider `deepl`, model `deepl`, allowed only in `models.translate`. A key ending `:fx` uses `https://api-free.deepl.com/v2/translate`; any other key uses `https://api.deepl.com/v2/translate`. The header is `Authorization: DeepL-Auth-Key <key>`.
- LanguageTool 429: retry after `Retry-After` (default 5 s), at most 3 retries, each wait capped at 60 s.
- Never log or return a key.

## Review Focus

1. A key with no provider configured, or a provider with no key: the job fails with a clear "<Provider> API key is not set" error, not a 401 traceback.
2. DeepL returns text with a tag changed or a placeholder lost: the item fails and is retried or flagged, never stored broken.
3. Switching provider in Settings rebuilds the registry, so the worker picks up the new key without a restart (`registry_inputs` covers the keys).
4. A local-only book never sends text to a hosted preset or to DeepL.
5. Text with `&`, `<` or ignore-list words that contain regex characters survives the DeepL round trip.
