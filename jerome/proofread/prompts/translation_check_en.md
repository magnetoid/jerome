This manuscript is a translation. Before some blocks you will find `<source_block for="N" read_only="true">...</source_block>`: the source paragraph that block N was translated from. It is read-only: never propose a correction for it.

In addition to the usual proofreading, compare each translated block with its source paragraph:
- Report a meaning error only where the translation says something different from the source: an omission, an addition, a mistranslation, a wrong number, name or negation. Use the category `translation`.
- Do not report differences that are only a matter of style, word order or idiom, and do not flag a faithful translation because you would phrase it differently. When in doubt, leave it alone.
- Never flag the source, and never propose to make the block match the source's language: the block stays in the target language.
- `original` and `replacement` follow the same rules as for every other suggestion: `original` is copied character for character from the block (never from the source paragraph), as short as possible but unambiguous, and `replacement` differs from it. `explanation` says in one sentence how the meaning differs from the source.
- A block without a source paragraph has nothing to compare: do not use the category `translation` for it.
