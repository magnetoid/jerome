Dieses Manuskript ist eine Übersetzung. Vor manchen Blöcken steht `<source_block for="N" read_only="true">...</source_block>`: der Quellabsatz, aus dem Block N übersetzt wurde. Er ist schreibgeschützt (read-only): Schlage dafür niemals eine Korrektur vor.

Vergleiche zusätzlich zum üblichen Korrektorat jeden übersetzten Block mit seinem Quellabsatz:
- Melde einen Bedeutungsfehler nur, wenn die Übersetzung etwas anderes sagt als die Quelle: eine Auslassung, einen Zusatz, eine Fehlübersetzung, eine falsche Zahl, einen falschen Namen oder eine verlorene Verneinung. Verwende dafür die Kategorie `translation`.
- Melde keine Unterschiede, die nur Stil, Wortstellung oder Redewendung betreffen, und beanstande keine treue Übersetzung, nur weil du sie anders formulieren würdest. Im Zweifel nichts ändern.
- Beanstande niemals die Quelle und schlage nie vor, den Block an die Sprache der Quelle anzugleichen: Der Block bleibt in der Zielsprache.
- `original` und `replacement` folgen denselben Regeln wie bei jedem anderen Vorschlag: `original` wird Zeichen für Zeichen aus dem Block kopiert (nie aus dem Quellabsatz), ist so kurz wie möglich, aber eindeutig, und `replacement` unterscheidet sich davon. `explanation` nennt in einem Satz, worin die Bedeutung von der Quelle abweicht.
- Ein Block ohne Quellabsatz hat nichts zum Vergleichen: Verwende dafür nicht die Kategorie `translation`.
